# API design

Opinionated patterns for designing developer-friendly HTTP APIs: a unified `issues` array for error and warning handling, and a model for a resource's state and events.

## Structure

- `SKILL.md` - Main skill instructions: principles, the `issues` pattern, the status/event/issue split, and design rules
- `references/error-handling.md` - Full field-by-field reference for the `issues` array
- `references/event-status-design.md` - Modelling and naming a resource's lifecycle: states, events, and the status/event/issue split
- `references/consuming-in-react.md` - TypeScript types and React/SDK consumption examples
